# 🧠 AI ส่วนตัว (AI_chat)

เว็บแชท AI ส่วนตัวที่ **จำเรื่องราวของคุณได้** — แยกโปรไฟล์หลายคน แต่ละคนมีสมุดความทรงจำและรหัสผ่านของตัวเอง
รันบน [Ollama](https://ollama.com) + โมเดลในเครื่อง (เริ่มต้น `qwen3:8b`)

## ต้องมีก่อน
- [Node.js](https://nodejs.org) 18 ขึ้นไป (ใช้ 22 ดีสุด)
- [Ollama](https://ollama.com) ติดตั้งและรันอยู่
- โหลดโมเดล: `ollama pull qwen3:8b`

## วิธีรัน
```bash
node server.js
```
เปิดเบราว์เซอร์ที่ **http://localhost:3005**

ตั้งค่าเพิ่มเติมผ่าน environment variable ได้:
- `PORT` — พอร์ตเว็บ (ค่าเริ่มต้น 3005)
- `OLLAMA_URL` — ที่อยู่ Ollama (ค่าเริ่มต้น http://localhost:11434)

## โครงสร้าง
```
server.js          เซิร์ฟเวอร์ (Node ล้วน ไม่ต้องลง dependency)
public/            หน้าเว็บ (เลือกโปรไฟล์ / แชท / ตั้งค่า)
profiles/<ชื่อ>/   สร้างอัตโนมัติเมื่อสร้างโปรไฟล์ (ไม่ push ขึ้น git)
  settings.json    โมเดล, num_ctx, รหัสผ่าน (เข้ารหัส)
  memory/*.md      สมุดความทรงจำของโปรไฟล์นั้น
```

## ฟีเจอร์
- 👥 หลายโปรไฟล์ แยกความทรงจำ + รหัสผ่านแยกกัน
- 📓 AI จดสิ่งสำคัญลงสมุดความทรงจำอัตโนมัติ (`[[JOT: ...]]`)
- 🔢 หน้าตั้งค่าแสดง **จำนวน token ของแต่ละไฟล์** และเทียบกับขนาดบริบท
- ⚙️ เลือกโมเดล / ปรับ num_ctx / แก้บุคลิก ได้ต่อโปรไฟล์
- 📄 เปิดอ่าน แก้ไข และลบไฟล์ความทรงจำได้จากหน้าเว็บ
